# Audiobook for Marc Lou fans who don’t read

I've made $3M with my 36 startups — spoken, because some of you won’t open the PDF.

Voice clone from public talks. Not Marc reading.

## Put this on your site

Static folder. No build.

```
git clone https://github.com/stefanopineda/for-marc-lou-fans-who-dont-read.git
```

Upload the folder to any static host, or copy it into `public/audiobook/` on a Next.js site and link to `/audiobook/`.

Demo: https://stefanopineda.github.io/for-marc-lou-fans-who-dont-read/

Delete `robots.txt` if you want it indexed.
